# Oracle PL/SQL Scripts

A collection of practical scripts, database routines, and evaluations developed in **Oracle PL/SQL**.

## Contents

* **`PARCIAL_1.sql`**: Anonymous PL/SQL block utilizing explicit cursors to compute sales commissions and employee incentive tiers based on sales volume per billing period.
* **`PARCIAL_2.sql`**: Advanced PL/SQL payroll processing routine featuring social security deductions (pension/health/union), currency conversion (UF), and robust transaction control with error logging.
